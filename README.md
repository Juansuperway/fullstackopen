# Full Stack Open

This repository contains my solutions to the exercises from the Full Stack Open course by the University of Helsinki.

The course focuses on modern web development using:

- React
- Node.js
- Express
- MongoDB
- TypeScript
- GraphQL

## Repository Structure

The repository is organized by parts following the official course structure:

- part0
- part1
- part2
- etc.

Each folder contains the exercises and projects for that section of the course.
